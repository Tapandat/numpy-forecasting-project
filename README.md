# 🏏 Random Module Cricket Project

## 📌 Overview

This project generates a synthetic cricket dataset using Python's `random` module and performs numerical analysis using `NumPy`.

It is designed as a foundational step for future work in:

* Data Analysis
* Machine Learning
* Cricket Performance Prediction

---

## 📁 Project Structure

```
random-module-cricket-project/
│
├── data/                  # (Future use) Store datasets (CSV files)
├── src/
│   ├── generate_data.py  # Dataset generation using random module
│   ├── numpy_analysis.py # NumPy-based data analysis
│
├── main.py               # Entry point of the project
└── requirements.txt      # Project dependencies
```

---

## ⚙️ Setup Instructions

### 1️⃣ Clone the Repository

```
git clone <your-repo-url>
cd random-module-cricket-project
```

### 2️⃣ Create Virtual Environment

```
python -m venv venv
```

### 3️⃣ Activate Environment

**Windows:**

```
venv\Scripts\activate
```

**Mac/Linux:**

```
source venv/bin/activate
```

### 4️⃣ Install Dependencies

```
pip install -r requirements.txt
```

---

## ▶️ How to Run

```
python main.py
```

## 📊 Sample Data Format

Each record contains:

```
[player_name, runs, balls, fours, sixes]
```

Example:

```
['Virat', 75, 52, 8, 2]
```
